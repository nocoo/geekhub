# 活动中心与设置布局

2026-09-20

右上角统一展示订阅抓取、自动/手动翻译、AI 摘要、正文提取和订阅诊断。活动中心按类型、状态、订阅源和关键词筛选；展开记录可查看时间、文章、错误信息、耗时，并打开文章或诊断订阅。界面使用 Basalt 色彩、Lucide 图标和等宽数据字，适配深浅主题与手机。

日志仍使用共享 `FeedLogCache` Durable Object 的内存数组，容量从 100 扩到 500 条，无 D1、DO storage 或文件写入。实例回收或部署后清空。AI、提取和诊断通过关联 ID 记录开始、完成或失败，缓存命中不重复记录。活动记录失败不改变原操作结果；未知内部错误不将供应商响应或凭据写入日志。中断任务的开始记录在两分钟后不再被当作正在运行。日志每 5 秒刷新，抓取或已知活动进行中每 1.5 秒刷新；后台标签页暂停轮询。

Toast 位于右下角，带 Lucide 图标、关闭按钮和较短停留时间。自动翻译继续静默，只更新活动中心；新文章自动载入时可以发出通知。

文章列表的空状态在列表可用空间中纵向居中。首次使用、无订阅分类、订阅已删除、搜索/筛选无结果、订阅暂无文章、抓取中、抓取失败和 API 读取失败分别提供合适的说明与操作，已有订阅不会再显示首次使用提示。

Settings 根据内容区域宽度重排字段。分类将名称、图标、完整颜色值、排序、保存和删除集中排列；按钮不收缩或折行，排序按钮不提交表单。订阅管理移除重复边框和常规状态标记，名称允许换行，图标尺寸固定。阅读、AI 和数据页采用同一套字段间距与窄屏布局，继续使用 next-ai 公共配置组件。

验证证据位于 `docs/evidence/settings-empty/`。HTTPS 本地预览检查包含 1440、390、320 px 宽度的所有设置页签及活动中心；活动预览使用浏览器拦截的示例数据，不写开发数据库。完整质量检查和隔离浏览器测试结果见该目录日志。未部署生产。

最终 `bun run quality` 退出码 0：[完整日志](evidence/settings-empty/final-quality.log)。G1、187 项 L1、108 项真实 HTTP 检查（33/33 API）、48 项桌面／手机 L3、gitleaks 与 OSV 均通过。语句／分支／函数／行覆盖率为 99.72%／97.93%／100%／99.92%。保留既有的 >500 kB 客户端 chunk 构建提示。初次回归发现旧请求断言未包含自动任务标记、浅色主题计数对比度不足；复测发现弹窗动画中的宽度测量竞态，分别修正断言、文字透明度和测量等待后完整重跑通过，未降低检查要求。
