# v1.4.2 Release Verification

Released on 2026-10-01. Root `package.json` is authoritative; the sidebar,
`/api/live`, feed User-Agent and Worker tag use 1.4.2. The explicit Z+1 request
is honored despite the intentionally incompatible removal of retired schema
and API fields. This release must not be rolled back to v1.4.1 code.

## Maintenance and Preservation

Automatic Release execution was temporarily disabled while CI ran; CI stayed
enabled. After the target SHA passed, queue delivery was paused without purging
messages. A temporary maintenance entry preserved production bindings, secrets,
Access and the Durable Object export, returned 503 with `Retry-After: 120` and
`Cache-Control: no-store`, and retried any delivered queue messages.

Maintenance was observed at 02:18:19 UTC. After a 120-second drain, a D1 Time
Travel bookmark and a read-only row snapshot were recorded in ignored local
operational storage. Release was re-enabled and manually dispatched with the
successful CI run ID. The normal deploy script applied migrations `0007` and
`0008` before building and deploying the application. Deployment completed at
approximately 02:22:02 UTC; queue delivery resumed at 02:22:47 UTC.

Pre/post snapshots matched exactly for the selected subscription fields,
article IDs/source IDs/reading flags/content lengths, category fields and
catalogue count: 43 feeds, 2,699 articles and 6 categories. No reader data was
removed. The old log table, scheduling index and three scheduling columns are
absent, and obsolete diagnostic snapshots were discarded. Snapshot hashes and
schema evidence are retained; raw rows, credentials and the recovery bookmark
are not committed.
