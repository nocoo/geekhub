# v1.4.0 release validation

Version is read from root `package.json`; the sidebar, health endpoint, feed
User-Agent, deployment tag and GitHub Release use the same value. `bun install`
reported no dependency changes. Local sidebar verification returned `v1.4.0`.

The initial release CI [35476450275](https://github.com/nocoo/geekhub/actions/runs/35476450275)
passed build, quality, security and HTTP checks but caught two desktop browser
issues on Linux. Deployment was blocked and the GitHub Release returned to draft.

- Native desktop scrollbars reduced a narrow settings color control to 106 px.
  The narrow category grid now reserves enough width by reducing its icon column
  and gaps, retaining the original 112 px minimum-width assertion.
- A render between smooth-scroll frames could compare a stale viewport anchor
  with the current row and cancel the animation. Anchors now compare content
  coordinates, so scroll movement is distinguished from actual layout shifts.
  Existing keyboard, history and background-insertion assertions remain intact.

No test thresholds, retry policies or hooks were bypassed. Local post-fix browser
validation passed all 52 desktop/mobile flows. See
[evidence](evidence/v1.4.0/post-fix-browser.log). The release tag is updated to the
corrected commit before publication; the original commit remains in Git history.
